# Revamped Website - Tostot Software Solutions Pvt Ltd

## Summary
This repository contains the revamped company website for **Tostot Software Solutions Pvt Ltd**. It is a static front-end web project that presents a modernized company profile, including pages for home, about, services, portfolio, products, jobs, and contact.

## Tech Stack
- **HTML5**
- **CSS3** (including Bootstrap)
- **JavaScript**

## How to Run

### Prerequisites
- A modern web browser (Chrome, Firefox, Edge, Safari, etc.)
- Git (optional, for cloning)

### Steps to Run Locally

#### Method 1: Direct Opening (Easiest)
1. Download or clone the repository
2. Locate the `index.html` file
3. Double-click `index.html` or right-click and open with your web browser

#### Method 2: Using Git Clone
```bash
git clone https://github.com/SURIYA-PRAKASH-E-S/web-ab.git
cd web-ab
open index.html
```

#### Method 3: Using Node.js (if dependencies are needed)
```bash
git clone https://github.com/SURIYA-PRAKASH-E-S/web-ab.git
cd web-ab
npm install
npm start
```
